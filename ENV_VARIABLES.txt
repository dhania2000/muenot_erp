==============================================================================
 MUENOT ERP - ENVIRONMENT VARIABLES
==============================================================================
 Copy the variables you need into your .env file (or your host's env settings).
 Values shown are EXAMPLES / placeholders - replace them with real values.

 Legend:
   [REQUIRED] app will not work without it
   [OPTIONAL] only needed if you use that feature
==============================================================================


# =============================================================================
# 1. CORE APP  [REQUIRED]
# =============================================================================

# Public base URL of this app (used for links + email tracking pixels).
# No trailing slash.
APP_URL=https://erp.muenot.co.in
NEXT_PUBLIC_APP_URL=https://erp.muenot.co.in

# Secret used to sign/verify login session cookies (JWT). Use a long random
# string, e.g. output of: openssl rand -base64 48
SESSION_SECRET=change-me-to-a-long-random-string

# Secret used to encrypt/decrypt values stored in the environment_variables
# table (department email credentials saved from the admin UI).
# Use a long random string. If you change it, previously saved values can no
# longer be decrypted.
SETTINGS_ENCRYPTION_KEY=change-me-to-a-long-random-string


# =============================================================================
# 2. DATABASE (MySQL)  [REQUIRED]
# =============================================================================

DB_HOST=localhost
DB_PORT=3306
DB_USER=muenot_erp
DB_PASSWORD=your-db-password
DB_NAME=muenot_erp


# =============================================================================
# 3. EMAIL - GENERIC FALLBACK  [OPTIONAL]
# =============================================================================
# These are used as a DEFAULT for any department that does NOT have its own
# department-specific variables set (section 4). If every department has its
# own values, you do not strictly need these - but it is good to keep one
# working fallback.
#
# Two ways to send mail (pick one per department):
#   A) SMTP        - standard mail server (ports 465/587)
#   B) Gmail API   - use this if your host BLOCKS outbound SMTP
#                    (symptom: "Timeout | code: ETIMEDOUT | command: CONN")

# ---- A) Generic SMTP ----
SMTP_HOST=smtp.hostinger.com
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=noreply@muenot.co.in
SMTP_PASS=your-mailbox-password
SMTP_FROM=Muenot <noreply@muenot.co.in>

# ---- B) Generic Gmail API (fallback) ----
GMAIL_CLIENT_EMAIL=service-account@your-project.iam.gserviceaccount.com
GMAIL_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\nMIIE...\n-----END PRIVATE KEY-----\n"
GMAIL_SENDER=noreply@muenot.co.in


# =============================================================================
# 4. EMAIL - PER DEPARTMENT  [OPTIONAL, but recommended]
# =============================================================================
# Each department sends from its OWN email address, so each department has its
# OWN set of variables. The app looks for the department-specific variable
# first, and falls back to the generic one from section 3 if it is missing.
#
# For EACH department you can configure EITHER SMTP or Gmail API (or both;
# Gmail API is used when its credentials are present, otherwise SMTP).
#
# Departments: SALES, HR, FINANCE, OPERATIONS, RECRUIT
# -----------------------------------------------------------------------------
